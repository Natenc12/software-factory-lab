# Let `serveStatic` answer POST requests so our form posts get the page back

## Problem

Our marketing site is mostly static pages served with `serveStatic`. Its forms post to static
"thank you" pages, for example `<form method="post" action="/thanks.html">`, and a small handler
elsewhere records the submission. Today every such form post ends on `404 Not Found`, even though
`/thanks.html` exists and a GET of the same URL serves it:

```ts
import { Hono } from 'hono'
import { serveStatic } from 'hono/bun'

const app = new Hono()
app.use('/*', serveStatic({ root: './public' }))

// GET  /thanks.html -> 200, the page
// POST /thanks.html -> 404 Not Found
```

## Why it matters

Visitors who fill in a form see an error page instead of the confirmation, and some of them submit
again. Static hosts we used before served the page for a POST, so our pages were written that way.

## Scope

**In**
- `serveStatic` (the shared middleware in `src/middleware/serve-static/`, which every runtime's
  `serveStatic` wraps): answer POST requests for existing files.
- Tests.

**Out**
- How GET and HEAD are served (paths, MIME types, precompressed files, `onFound` / `onNotFound`).
- The runtime wrappers in `src/adapter/*/serve-static.ts`, except as needed to pass options through.
- The separate packages under `adapters/`.

## Decisions

- A POST to a path that `serveStatic` would serve for GET gets the same response as the GET: `200`,
  the file's body and its `Content-Type`.
- A POST to a path with no file behaves as today.

## Done when

- [ ] `POST /thanks.html` answers `200` with the page, as `GET /thanks.html` does.
- [ ] Tests for the new behaviour; every existing test passes.
- [ ] `pnpm test` passes (after `pnpm run build`), and `pnpm run lint` and `pnpm run format` are clean.

## Notes for the implementer

- `src/middleware/serve-static/index.test.ts` drives the shared middleware with a stand-in
  `getContent`, so no files or runtime are needed.
- Install with `pnpm install`, build with `pnpm run build` (the tests in `build/` need it), then run
  `pnpm test`. A single folder runs with `pnpm exec vp test --run src/middleware/serve-static`.
