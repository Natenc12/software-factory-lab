# index part of a too-long file instead of failing it

Students uploading full textbooks get "too_long" and give up. Instead of failing those, index the first
250,000 words and mark the file ready. The status page should say only part was indexed and give the
file's word count, like "Only the first 250,000 of this file's 312,400 words were indexed." Don't
change the limit itself.
