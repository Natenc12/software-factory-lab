# delete an uploaded file

Students can't remove a file once it's uploaded, so a wrong or outdated lecture keeps showing up in
answers. Add a way to delete a file: `delete_file(conn, file_id=..., owner_id=...)` in `files.py`
(True if it deleted something, False if there was no such file) plus `DELETE /files/{file_id}` (204,
or 404 like GET does). It should get rid of the chunks, the job, the files row and the staged upload
on disk. Don't let someone delete another owner's file. Shouldn't delete a file while the worker is
in the middle of it: raise a `FileBusy` error and answer 409 `file_busy`.
