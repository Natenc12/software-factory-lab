# API should say "course" not "class"

We're renaming "class" to "course" in the product. Add `POST /courses` (returns `course_id`) and let
`POST /files` and `POST /ask` take `course_id`. Old clients still send `class_id` and hit
`POST /classes` and must keep working exactly as now. Errors for course requests should say course
(`course_not_found`, `bad_course_id`). If someone sends both ids and they don't match, refuse it
(`conflicting_ids`). Mark `POST /classes` deprecated in the OpenAPI. Don't rename anything in the
database or the library.
