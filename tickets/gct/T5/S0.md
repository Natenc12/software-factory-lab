# no duplicate class names

Saw a student with two classes both called "Biology 101" - they created it twice and their uploads
got split between them. Creating a class should refuse a name the student already has. Add a
`ClassNameTaken` error in `classes.py` for it, and have POST /classes answer 409 `class_name_taken`.
Other students can use the same name. Don't touch classes that are already duplicated.
