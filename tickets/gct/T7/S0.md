# page_or_slide should be an int column

`chunks.page_or_slide` is a text column but it's always a page number. The code converts int -> str
when indexing and str -> int when retrieving, and sorting by it puts 10 before 2. Let's make it an
integer column. There's already data in the database, so it needs a migration that keeps the existing
chunks. Pages should never be below 1. Update index_file/retrieve and the tests.
