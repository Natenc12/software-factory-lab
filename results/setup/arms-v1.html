The arms I will freeze

Six ways of working the same ticket. Same model, same effort, same sandbox, same stand-in owner. Only the instructions differ. Order is simplest first, which is also the tie-break order.

  • Why add P1R. P2 and P3 each bundle a reviewer with a lot of other process. P1R shows whether the reviewer alone gives most of the gain. If it does, your winning checklist can be one page. In race 1, on the same Opus generation as now, reviewers found real bugs.
  • P4's limits are now real. The scout showed Claude Code can refuse a role's attempt to read a folder. So "the tester never sees the code" is enforced by the tool, not requested in a prompt. Script scout trial
  • Effort is now a fixed setting. Race 1 never controlled it. Left alone it would be a hidden difference between runs.

How I used the research, given your concern

You said findings on Claude 4-era models can't be trusted for the 5.5 generation. I agree, and the research agent redid its report with that rule: every finding now carries the model and date it was tested on. The outcome: old evidence changed no arm. It only added things to measure.

Adopted: true for any model

These are about running a fair test, not about how a model behaves.

  • No run can see another run, the answers or the real repo. Built into the harness.
  • The auditor checks each hidden test isn't too narrow (demands one exact fix) or too wide (checks things the ticket never asked).
  • Before the freeze, the grader must pass every reference fix and fail every empty change.
  • A scripted trap for editing an existing test the ticket didn't ask to change.
  • A run's new tests must fail on the starting code, or they prove nothing.
  • Replay tickets come from after the models' June 2026 training cutoff. GCT's whole history starts July 6, 2026, so all of it qualifies. Script

Kept as guesses our runs will test

Evidence on current models is thin or missing. No arm changed.

  • "Models game the checks when a ticket is broken." The flawed ticket measures it.
  • "Models edit tests to make them pass." Opus 4.1 only. The trap measures it.
  • "A fresh reviewer beats self-review." No current study. P1R measures it.
  • "Models don't ask unless told to." No Claude 5 data. The vague ticket measures it.
  • "Splitting the writing across agents hurts." One October study, on Opus 5. P4 against P3 measures it.
  • "More context and paperwork doesn't help." The spec levels measure it.
