#7 Class summary counts hidden questions: PR #21

Refresher

The problem. When a teacher hid a question, it vanished from the list, but the class summary still counted it in total. Since unanswered is total - answered, the "still waiting" number went up by one for every hidden question.

The solution. The class total now comes from count_questions, the function that already counts only visible questions for the question list. Nothing else in the summary changes: same keys, same unanswered = total - answered, and student_breakdown is untouched.
