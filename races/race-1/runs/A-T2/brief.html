Follow-up (kept here, not filed)

You said no GitHub actions beyond the PR and the in-progress label, so this stays on the page instead of becoming an issue. CSV export: cells starting with = + - @ open as formulas in spreadsheets. Question and answer text is typed by students and goes into the CSV as stored. A spreadsheet reads a cell like =HYPERLINK("http://example.com","click") as a live formula. The usual fix is a leading ', but that breaks #3's rule that the export round-trips the stored text, so it needs a decision first: neutralise or not, and which columns.
