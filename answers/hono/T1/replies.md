# T1 replies (stand-in owner)

## T1-which-value
When: The developer asks whether a repeated parameter name should give the first value, the last value, or something else (such as an array of all values).
Reply: The first value, in every position and for every router, as the existing "self" test already says.

## T1-smart-router-question
When: The developer asks whether they may change how `SmartRouter` picks a router, or which router a given app ends up with, and has not done it.
Reply: No, leave router selection as it is; it is out of scope. Make the routers agree instead.
